# sorting-algorithms-core

Самостоятельный Git-репозиторий с Python-алгоритмами сортировки. Подключается к `sorting-app` через `git submodule add` как папка `algorithms`.

Исходная версия: пузырьковая сортировка и сортировка вставками. В ходе практической работы новые реализации добавляются отдельными коммитами.

Проверка из корня этого репозитория:

```bash
python -m unittest discover -s tests -v
```
